# 论文参考与当前实现对应关系

## 1. FAVOUR：核心数学与流程参考

论文：
[FAVOUR Personalized Situation-Aware Multimodal Routes](../../paper/个性化推荐服务核心论文/02_FAVOUR_Personalized_Situation_Aware_Multimodal_Routes_2017.pdf)

当前实现直接对应：

- 公式（4）（5）：路线成对选择的 Bradley-Terry/Logit 概率与联合似然；
- 第 IV-A 节：Gaussian 先验、后验众数和 Laplace Gaussian 协方差；
- 公式（6）：把上一次后验作为下一次先验的增量 Bayes 更新；
- 公式（7）：多个个人 Gaussian 后验聚合为 MPP；
- 公式（8）（9）：积分掉后验不确定性后的近似选择概率；
- 第 VI-C 节：box-bounded 优化、解析导数和 Hessian。

论文使用效用系数 $w$，时间、费用等代价通常对应负值。项目使用正向代价
敏感度 $\theta=-w$ 和差向量 $rejected-chosen$。这个符号变换保持 Logit
指数完全相同，便于把正数解释为“越不愿承受该项代价”。

对应代码包括 `inference.py`、`optimization.py`、`priors.py` 和 `service.py`。

## 2. Preference-Aware Multimodal Journey Planner：归一化与展示参考

论文：
[Preference-Aware Multimodal Journey Planner](../../paper/个性化推荐服务核心论文/01_Preference_Aware_Multimodal_Journey_Planner_2026.pdf)

当前主要参考其不同量纲路线属性在组合前需要归一化的思想。项目使用固定业务
尺度而不是每个候选集内的 min-max，保证同一系数在不同出行之间含义稳定。

该论文的“非负且总和为 1”约束只用于当前项目的四维展示百分比。FAVOUR 核心
模型系数不再做单纯形投影，否则会错误限制 Logit 的尺度。

对应代码为 `normalization.py` 和 `service.py` 中的展示组件。

## 3. 旅客异质性画像论文：画像含义参考

论文：
[基于旅客异质性画像的公铁联程出行方案推荐方法](../../paper/个性化推荐服务核心论文/03_基于旅客异质性画像的公铁联程出行方案推荐方法_2022.pdf)

该论文用于支持“用户画像可表达对时间、费用等代价的敏感程度，并进入后续
推荐目标”的概念。当前路线成对选择实现没有直接使用其 TF-IDF、K-means 或
Q-learning 算法。

## 4. 当前项目自己的工程设计

以下内容不是论文提供的通用参数：

- 四维缩减特征，而不是 FAVOUR 实验中的完整路线和情境特征；
- 6 组比较题的具体路线数值；
- 180 分钟、100 元、3000 米、4 次的默认归一化尺度；
- 固定等权 Gaussian 冷启动先验及其边界；
- 纯 Python 的阻尼 Newton 和内存后验仓库；
- 终端展示文案及四维百分比。

完整公式、每个文件职责、数据交互和验证范围见
[FAVOUR实现与模块交互说明](FAVOUR实现与模块交互说明.md)。
